각도(순서대로, 각도마다 diff 전체) —
1. 정확성: 줄 단위 논리 · 경계값 · null · 예외 경로. 지워진 동작(삭제된 분기 · 조건이 좁아진 곳)이 쓰이던 자리.
2. 파일 사이: 바뀐 메서드의 호출처 전부. 시그니처 · 반환 의미 · 예외가 바뀌었는데 호출처가 그대로인 곳.
3. 누락: 계약 변경 뒤 빠진 처리 · 검증. 바뀐 테스트 — assertion 이 새 동작에 맞춰 고쳐진 것은 결함 후보다. 지시서 성공 기준 가운데 코드에 대응이 없는 것. 새 `[SerializeField]` 필드 · 새 컴포넌트 · 새 프리팹 참조가 씬 · 프리팹 연결을 필요로 하면 표시한다.
4. 검토 기준 대조: 「검토 기준」 절의 항목(코딩 표준 전체 포함)마다 이 diff 에 해당하는 곳이 있는지, 지켜졌는지.
5. 범위: 수정 허용 영역 밖 변경, 요청에 없는 기능 · 리팩터링.
6. 이해: 읽고도 왜 이렇게 했는지 모르는 곳. 설명 없이 그대로 두면 다음 사람도 막힐 곳.

쓰지 않는 것 — 스타일 · 포맷 · 주석 문구 · 이름 취향. 결정론 층(분석기 · 포매터)의 일이다.
